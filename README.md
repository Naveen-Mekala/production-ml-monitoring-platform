# Production ML & Model Monitoring Platform

An end-to-end machine learning engineering project that serves predictions through a REST API and monitors model inputs, prediction activity, data quality, and potential drift.

## Objectives

- Train and save a reproducible machine learning model.
- Serve predictions through a FastAPI REST API.
- Validate incoming requests using Pydantic.
- Track prediction requests and model performance.
- Detect changes in incoming data distributions.
- Build a monitoring dashboard.
- Containerize the application with Docker.
- Add automated tests and documentation.

## Technology Stack

- Python
- pandas and NumPy
- scikit-learn
- FastAPI and Uvicorn
- Pydantic
- PostgreSQL
- Streamlit
- Docker
- pytest

## Project Status

Initial project setup completed. Data preparation, model training, API development, monitoring, testing, and deployment are planned next.
